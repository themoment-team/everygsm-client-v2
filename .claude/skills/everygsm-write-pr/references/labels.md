# EveryGSM GitHub Labels Reference

Select 1-2 labels from the PR-eligible list below. Do not assign issue-only or manual-status labels.

## PR-Eligible Labels

| Label                  | When to Use                                                |
| ---------------------- | ---------------------------------------------------------- |
| `enhancement:개선작업` | New feature, improvement, refactor, or harness improvement |
| `bug:버그`             | Bug fix                                                    |
| `documentation:문서화` | Documentation-only changes                                 |
| `release:릴리즈`       | Release preparation or version bump                        |

## Off-Limits Labels

| Label                          | Reason                             |
| ------------------------------ | ---------------------------------- |
| `waiting for review:검토 대기` | Applied manually after PR is ready |
| `help wanted:도움 필요`        | Issues only                        |
| `invalid:무효한`               | Issues only                        |
| `duplicate:중복`               | Issues only                        |
| `GFI:첫 기여 추천`             | Issues only                        |
| `blocked:차단됨`               | Applied manually when blocked      |

## Quick Decision

```text
Bug fix? -> bug:버그
Docs only? -> documentation:문서화
Release? -> release:릴리즈
Everything else? -> enhancement:개선작업
```
